SÄVELKOJU PWA – ASENNUS

iPad / iPhone
1. Avaa GitHub Pages -osoite Safarissa.
2. Paina Jaa.
3. Valitse Lisää Koti-valikkoon.
4. Varmista tarvittaessa, että Avaa verkkosovelluksena / Open as Web App on käytössä.
5. Käynnistä Sävelkoju tämän jälkeen Koti-valikon kuvakkeesta.

Android / Chrome
1. Avaa GitHub Pages -osoite Chromessa.
2. Valitse selaimen valikosta Asenna sovellus / Lisää aloitusnäyttöön.
3. Käynnistä Sävelkoju omasta kuvakkeesta.

PWA-RAKENNE
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- icon-maskable-512.png
- apple-touch-icon.png

OFFLINE
Pelin paikalliset HTML-, JavaScript-, CSS-, kuva-, video- ja äänitiedostot
välimuistitetaan. Firebase-tulostaulun lukeminen/tallentaminen vaatii internetin.

PÄIVITYKSET
Service worker käyttää verkkoa ensisijaisesti. Kun GitHub Pagesissa on uusi
versio ja laite on verkossa, uudet resurssit haetaan ja samalla päivitetään
välimuistiin.


HUOM: Tässä versiossa PWA ei tallenna sovellustiedostoja offline-cacheen. Käynnistys vaatii verkkoyhteyden ja tiedostot haetaan aina palvelimelta.
