Ääninäyte DEV 0.3.20 UI LAB

Muutokset 0.3.20:
- Tallennetut näytteet esitetään sävelittäin avattavina kortteina.
- Kortissa näkyy sävel, näytteiden määrä ja referenssin/varoituksen tila.
- Kortin avaamalla näkee yksittäiset näytteet ja niiden Hz-arvot.
- Yksittäisen näytteen tai koko sävelryhmän voi poistaa.
- Minipelin näyttö, TESTAA-nappi ja koko minipelilogiikka on poistettu toistaiseksi.
- UI DEV säilyy, ja sävelkorttien keskeiset mitat ovat säädettävissä sekä mukana UI-JSONissa.
- 0.3.19:n UI DEV -asetukset luetaan varalta myös vanhasta localStorage-avaimesta.
