Pikakirjoitin 2 Core 0.22.10 – Asettelusäätimet

Pohja: 0.22.7 Enharmoninen sävellajin mukaan.

Uutta:
- Pikakirjoittimen sisäinen ASETTELU-paneeli.
- Otsikko Y: otsikko pysyy keskitettynä, vain pystysijaintia säädetään.
- Tempo X ja Tempo Y: tempotekstiä voi siirtää vapaasti.
- Säveltäjä Y: säveltäjä pysyy viivaston oikeassa reunassa, vain pystysijaintia säädetään.
- Säädöt näkyvät millimetreinä ja päivittyvät nuottipaperille heti.
- Palauta palauttaa oletusasettelun.
- Kopioi JSON kopioi nykyiset asetteluarvot leikepöydälle käyttäjän lähetettäväksi.
- Arvot säilyvät localStoragessa.

Muu 0.22.7:n nuotinnus- ja editointilogiikka on jätetty ennalleen.
