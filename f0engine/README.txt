F0 ENGINE · BASE 2.0 vs PROFILE FAST 1 · OSMD

Tarkoitus:
Näytä BASE 2.0 ja PROFILE FAST 1 vierekkäin reaaliajassa.
Kummallakin on oma OSMD-nuottinäyttö.

Tiedostot:
- index.html
- f0-engine-base.js
- f0-engine-profile.js
- profiles.js
- opensheetmusicdisplay.min.js

Vertailu:
- BASE 2.0 käyttää alkuperäistä BASE 2.0 -moottoria.
- PROFILE FAST 1 käyttää PROFILE FAST 1 -moottoria profiililla:
  g¹, a¹, h¹, c², d²
  2 peräkkäistä framea
  ±30 cent

Sivu näyttää kummankin hyväksytyn sävelen, F0:n ja sävelenvaihdon ajan.
Kun molemmat ovat päätyneet samaan uuteen säveleen, sivu näyttää
kumpi ehti siihen ensin ja eron millisekunteina.

Tärkeää:
Moottorien algoritmeja ei muutettu tätä vertailua varten.
Ainoastaan selainglobaalien nimet vaihdettiin, jotta molemmat voidaan
ladata samalle sivulle.
