- Oletuskoko 180 %.
- Koskettimisto siirretty apin alareunaan.
- Koskettimisto on nyt oikeasti 3 oktaavia: c – c³.
  - MIDI 48 ... 84
- Musta pallo näyttää valitun sävelen soivan koskettimen.
- C / B♭ / E♭ / F -soitinvire säilyy.
- OSMD ja viritysmittari reagoivat vain valittuihin säveliin.
