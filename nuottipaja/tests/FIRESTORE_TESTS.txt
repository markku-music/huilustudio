Paikallisten Firebase-sääntötestien suorittaminen

Testi käyttää vain paikallista Firestore-emulaattoria ja kuvitteellista
demo-nuottipaja-projektia. Firebase-kirjautumista tai pilviprojektia ei tarvita.
Testi ei julkaise sääntöjä eikä kirjoita nykyiseen Firebase-projektiin.

Edellytykset: Node.js ja Java 17 tai uudempi. Testattu Node 24:llä, Java 17:llä,
Firebase CLI 13.35.1:llä ja Firestore Emulator 1.19.8:lla. CLI on tarkoituksella
kiinnitetty versioon 13.35.1; uusin CLI vaatii Java 21:n.

Suorita projektin juuresta:

  cd tests
  npm install --no-audit --no-fund
  npm run test:rules

Ensimmäinen suoritus lataa virallisen paikallisen Firestore-emulaattorin.
firestore-rules.test.mjs lukee ../firebase/firestore.rules-tiedoston suhteessa
omaan sijaintiinsa ja lataa säännöt emulaattoriin ennen tarkistuksia.

Viimeisin tulos: kaikki 35 tarkistusta läpäisty. Mukana ovat huoneen luonti,
koodikohtaiset lukuoikeudet, huoneluettelon lukemisen esto, vastakkaisen roolin
liittyminen, kolmannen pelaajan esto, toisen osuuden ja omistajan muuttamisen
esto, oma sävel/aika-arvo, uudelleenaloitus, vanhan kierroksen torjunta,
poistuminen, tehtävänvaihto yksin, vanhentunut huone ja kaksi samanaikaista
viimeisestä pelaajapaikasta kilpailevaa Firebase-transaktiota. Myös aiemman
Puhallinstartti-tulostaulun luonti- ja päivityssäännöt tarkistetaan.

Odotetuista kielletyistä kirjoituksista emulaattori tulostaa PERMISSION_DENIED.
Onnistunut testi päättyy tekstiin "All 35 Firebase rule checks passed."

Emulaattorin ajon yhteydessä syntyvät lokit ja node_modules-kansio ovat vain
paikallisia työvälineitä. Niitä ei tarvitse jakaa koepelin mukana.
