HUILUSTUDIO ADMIN

1. Julkaise tämä kansio GitHub Pagesiin polkuun /SavelkojuAdmin/.
2. Kirjaudu Firebase Authenticationiin luodulla opettajatunnuksella.
3. Firestoressa pitää olla admins/{OPETTAJAN_UID} dokumentti.
4. Julkaise paketin firestore.rules Firestore Rules -välilehdellä.

Ensimmäisellä käyttökerralla Tasot ja Palkinnot voivat olla tyhjiä. Lisää ne Adminin omilla painikkeilla.
